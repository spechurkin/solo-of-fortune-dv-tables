# Solo of Fortune DV Tables

Модуль Foundry VTT v12 с расширенными таблицами СЛ по дистанции из
`Solo of Fortune` для системы `Cyberpunk RED - CORE` v0.92.4.
Compendium собран в формате, описанном в
[документации CPR Core по DV Tables](https://gitlab.com/cyberpunk-red-team/fvtt-cyberpunk-red-core/-/wikis/System-Documentation/DV-Tables).

## Использование:

1. Включить модуль
2. Скопировать библиотеку
